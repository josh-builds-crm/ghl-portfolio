Featured Case Study

Case Study Solar Industry

Automated Calendar System for Solar Sales Team

Client
Regional Solar Co. (USA)
Team Size
100+ Sales Agents
Timeline
8 Weeks
Tools
GHL, Zapier, Google Sheets, ChatGPT

01. Objective

Streamline the booking system so that when a lead submits their zip code, they are automatically assigned to a regional sales manager and then to the nearest sales agent on their team — eliminating manual appointment routing while maximizing response time and coverage.

02. Solution Implemented

  • →Designed a 2-step lead form on a GHL landing page to collect zip code, email, and phone.
  • →Built a Zapier workflow that checks the zip code against a Google Sheets master list mapped by region.
  • →Automatically assigned leads to the right regional sales manager and suggested the closest field rep based on Google Maps proximity.
  • →Synced all bookings into Google Calendar, with custom confirmation emails and reminders sent via GHL.
  • →Created pipeline dashboards for regional managers to track agent performance and lead conversion rates.

03. Results

< 5 min
Lead-to-agent assignment time (down from 2+ hours)
30%
Improvement in booked appointments in the first 4 weeks
10+ hrs/wk
Saved by regional managers on lead routing
Instant
Notifications to sales agents, increasing follow-up speed

04. Lessons Learned

  • ✦Always include a fallback routing system in case a zip code is unassigned.
  • ✦Agent performance improves with real-time visibility and clear follow-up SOPs.
